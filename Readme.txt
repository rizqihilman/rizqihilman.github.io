Sebelum melakukan push, pastikan Anda telah menyelesaikan langkah-langkah berikut di folder proyek lokal Anda: 
Inisialisasi Git: git init
Tambahkan file: git add . (menambahkan semua file) atau git add <nama_file>
Lakukan commit: git commit -m "Pesan commit Anda"

Perintah untuk Push ke GitHub 
Setelah prasyarat terpenuhi dan Anda memiliki perubahan baru yang telah di-commit secara lokal, gunakan perintah berikut di terminal Anda: 
Pastikan Anda berada di branch yang benar (biasanya main atau master):
bash
git branch -M main
Perintah ini memastikan branch lokal Anda bernama main, sesuai standar GitHub saat ini.
Lakukan push perubahan Anda:
bash
git push -u origin main
git push adalah perintah untuk mengunggah konten repositori lokal ke repositori remote.
origin adalah nama remote default yang merujuk pada URL repositori GitHub Anda.
main adalah nama branch yang Anda dorong perubahannya.
-u (atau --set-upstream) digunakan saat pertama kali Anda mendorong branch baru untuk menautkan branch lokal dengan branch remote, sehingga untuk push berikutnya Anda cukup menggunakan git push saja. 
Setelah menjalankan perintah git push, refresh halaman repositori GitHub Anda di browser untuk melihat perubahan yang telah terunggah.
